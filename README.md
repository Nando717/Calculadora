
# Calculadora

Projeto desenvolvido durante minhas aulas iniciais da EBAC.

Este projeto contém:

- `calculadora.py` → código da calculadora desenvolvido em Python
- `calculadora.sh` → arquivo executável responsável por executar automaticamente a calculadora

---

## Como funciona o código Python

O arquivo `calculadora.py` executa uma calculadora bem simples.

Funcionalidades:

- Soma
- Subtração
- Multiplicação
- Divisão

Fluxo:

1. O usuário escolhe a operação.
2. O sistema solicita dois números.
3. O programa realiza o cálculo.
4. O resultado é exibido na tela.
   

Cada operação tem um código.
- Soma = 1
- Subtração = 2
- Multiplicação = 3
- Divisão = 4

Exemplo:

Operação: 1  
Número 1: 10  
Número 2: 5  

Resultado:

15

---

## Como executar o arquivo executável (.sh)

No terminal Linux:

Dar permissão de execução:

```bash
chmod 744 calculadora.sh
```

Executar:

```bash
./calculadora.sh
```

O script executará automaticamente o arquivo Python da calculadora.
